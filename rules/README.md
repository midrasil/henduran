# Wiki de regras — Henduran

Esta pasta será a **fonte de verdade textual das regras utilizadas no Henduran**. As regras partem do sistema [Astra](https://github.com/midrasil/astra-rules), mas passam por adaptações específicas para o RPG solo contínuo conduzido por IA.

**Status:** estrutura reservada. Nenhuma seção de regras adaptadas está aprovada ou publicada aqui ainda.

## Diretrizes

- Publicar somente regras adaptadas, revisadas e aprovadas para o Henduran.
- Não implementar inicialmente **Competências e Capacidades**.
- Adaptar referências a sessões de RPG de mesa, especialmente Ambição, Desejo, Convicções, Pilares e XP, sem transformar automaticamente cada Cena em sessão.
- Deixar claro quando uma regra é interpretativa e quando deve ser executada pelo motor.
- Manter links para a regra de origem e registro das diferenças da adaptação.
- Garantir correspondência entre a wiki, o motor de regras e seus testes.

Leia também [Adaptação do Astra](../docs/03-adaptacao-astra.md).
